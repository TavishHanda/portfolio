A Chrome extension for taking control of cookies: see what a site has set, edit or delete cookies per site, and keep lists of trusted and blocked sites. Built for a computer security course using Chrome's Manifest V3 cookies API. It runs as a real installed extension in Chrome, loaded directly rather than through the Web Store.
